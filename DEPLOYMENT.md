## Quick Hosting Methods

### Method 1: Netlify Drop (Easiest - 1 Minute, Free)
1. Run the build command in your terminal:
   ```bash
   npm run build
   ```
2. Open [https://app.netlify.com/drop](https://app.netlify.com/drop) in your browser.
3. Drag and drop the `dist` folder generated by the build into the upload area.
4. Your website is immediately online with an instant free HTTPS URL!

---

### Method 2: Vercel (Recommended for GitHub)
1. Push this project to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of STET 20 Test Series"
   git branch -M main
   git remote add origin https://github.com/<your-username>/stet-test-series.git
   git push -u origin main
   ```
2. Go to [https://vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your repository. Vercel automatically detects Vite with:
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**. Any future commits will automatically update the live site!

---

### Method 3: GitHub Pages (Free Static Hosting)
1. In `vite.config.ts`, set the base path if hosting on a subpath (e.g. `base: '/stet-test-series/'`).
2. Build the project:
   ```bash
   npm run build
   ```
3. Deploy the `dist` folder to your `gh-pages` branch or use GitHub Actions.

---

### Method 4: Node.js Server / Render / Railway / Docker
This application includes a self-contained production Node server (`server.cjs`).
To run it on any server or VPS:
```bash
npm install
npm run build
npm start
```
The server will run on port `3000` (or the port specified by the `PORT` environment variable).
